# Assayist docs

- `contract-v0.md`: the metric contract spec (normative). The load-bearing
  agreement every gadget, the orchestrator, and the gate share.
- `architecture.md`: the design brief. Why one system spans every problem
  space (spine plus adapters), and how the pieces fit.
- `compatibility-matrix.md`: per-kernel field and tracepoint dependencies for
  the eBPF gadgets, with kernel floors and failure modes.

Machine-checkable schema lives at `../contract/assay-run.schema.json`.
